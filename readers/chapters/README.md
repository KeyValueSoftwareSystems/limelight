# chapters — the twenty-line reader

Map in, chapter list out. Nothing about lights.

```
$ python chapters.py ../../maps/example.map.json
00:00 intro
00:04 build
00:08 drop
00:13 outro
```

Read `chapters` from the map, format the seconds as mm:ss, print. That is the whole program.

## Why this tiny thing is on the critical path

On the 18th, right after the lights, we show this and say two words: **"same file."**

A judge who watches a room detonate might believe we built a clever light show. A judge who
then sees YouTube chapters fall out of the identical file understands, without any explanation,
that the light show was one consumer of something more general.

Twenty lines. Highest ratio of argument to effort in the whole repo.
