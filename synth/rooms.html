Flash match is the number that matters: it asks whether the two rooms change at the same instants, which is what an audience sees. Levels match asks whether they are on average equally bright, and it is generous to the point of dishonesty — a room firing on the wrong half of the beat still scores 98% on it.
Left is the show built from the reference map. Right is the show built from a map with one thing wrong. Same song, same rig, same recipe — the only difference is the file. This is what a map error costs, which is not something a beat-accuracy number can tell you.
