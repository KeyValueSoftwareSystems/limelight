If nothing loads



  
Three commands, once. Python 3 only — no pip, no node, no network, nothing to unzip.

  
python3 synth/compose.py   makes all ten songs, audio and answers together
     (about 90 seconds)

  
python3 synth/loop.py   scores the example listener — this is the number to
     beat

  
python3 synth/serve.py   serves this page

  
Audio is never stored, only generated. 14 KB of code writes every song identically on every
     machine, so two people cannot end up listening to different things without knowing.





Two rules that do not bend. No song files in git, ever — we ship the generator, not
the audio. And never fill a field you did not verify: an empty value is worth more than a guess,
because once a guess is written down nobody can tell it apart from a measurement.
