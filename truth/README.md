# Truth

The only files in this project that cannot be generated. Made by a human with the audio playing.

Read `PROTOCOL.md` before writing one. The short version: **never fill a field you did not
verify.** `null` is a legitimate answer and it is worth more than a guess, because a guess is
indistinguishable from a measurement once it is written down — the bench number still prints, it
is just measuring nothing.

`the-nights.truth.synthetic.json` is a **stand-in**, derived from a sketch map so that the bench
runs on day one. It is not a listening record and no number derived from it should be quoted to
anyone. Replace it.

Renjith owns truth and taste. Not by seniority — because a person who both builds the model and
decides what counts as correct will grade generously, and not through dishonesty. Through hope.
