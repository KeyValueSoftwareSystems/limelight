# songs

One folder per song. **Audio never gets committed** — it is gitignored. Bring your own copy.

```
songs/the-nights/
  audio.mp3     <- yours, local, never pushed
  truth.json    <- what a human says is actually there
```

## Making a truth file

Copy `the-nights/truth.template.json`, open the song, and fill the blanks by ear. Use the
tapper in `score/` once it exists.

**You do not need every beat.** Tap one clean thirty-second window and record which window it
was. The chapters and moments are what matter, and they need to be right to about a tenth of a
second.

## The one rule

Nobody guesses a timestamp. Nobody copies one from the internet. Nobody asks a model to
estimate one. **Truth comes from a human with the audio playing.** One invented number makes
every score afterwards a lie, and the lie is invisible.
